# Web API Signature & Request Signing Reverse Engineering Playbook

This technical playbook provides an end-to-end operational guide for analyzing, tracing, and reproducing dynamic client-side HTTP request signatures (`X-Sign`, `token`, `nonce`, HMAC digests) in Single-Page Applications and WebViews.

---

## 1. Request Signing Architecture & Mental Model

Modern web applications protect internal REST and GraphQL endpoints against automated scraping and replay attacks by attaching dynamic cryptographic signatures:

```
[User Action: Click Search / Order]
                 │
                 ▼
[1. Gather Input Data] ──► Query Params + JSON Request Body + Timestamp + Nonce (UUID)
                 │
                 ▼
[2. Canonicalization] ──► Sort Query Keys alphabetically + Strip JSON Whitespace
                 │
                 ▼
[3. Payload Construction] ──► CanonicalString = "PATH|SORTED_QUERY|COMPACT_JSON|TIMESTAMP|NONCE|SECRET_KEY"
                 │
                 ▼
[4. Cryptographic Hashing] ──► Hash = HMAC_SHA256(CanonicalString, SecretKey)
                 │
                 ▼
[5. Header Injection] ──► Attach: X-Sign: <Hash>, X-Timestamp: <Timestamp>, X-Nonce: <Nonce>
                 │
                 ▼
[6. Network Dispatch] ──► fetch() / XMLHttpRequest -> Backend API Server
```

## 2. Dynamic Tracing Methodology: Call Stack Localization

Never attempt to locate signature algorithms by randomly reading minified code. Always use **Call Stack Tracing**:

### Step-by-Step Procedure:
1. **Inject Fetch / XHR Hook:**
   Open Chrome DevTools Console and execute the hook generated by `scripts/devtools_hook_generator.py --mode fetch-xhr`:
   ```javascript
   const origFetch = window.fetch;
   window.fetch = async function(...args) {
     console.groupCollapsed(`[FETCH] ${args[0]}`);
     console.log('Headers:', args[1]?.headers);
     console.log('Call Stack:\n', new Error().stack);
     console.groupEnd();
     return origFetch.apply(this, args);
   };
   ```
2. **Trigger the Target Action in the Browser:**
   Click the target button (e.g. "Search", "Next Page", "Checkout").
3. **Inspect the Console Group:**
   The console outputs the exact stack trace:
   ```
   [FETCH] POST /api/v2/order/create
   Headers: { X-Sign: "8f2a1b9e...", X-Timestamp: "1741165200" }
   Call Stack:
       at signRequest (sign.ts:45:12)
       at AxiosInstance.request (axios.js:120:8)
       at OrderService.submit (order.js:88:5)
   ```
4. **Jump to Source & Set Breakpoint:**
   Click `sign.ts:45:12` in DevTools. Set a breakpoint on the `signRequest` function line.
5. **Inspect Local Scope Variables:**
   When the breakpoint hits, inspect the `Scope` panel to observe the exact plaintext string fed into the hashing function and the secret key variable.

## 3. Common Canonicalization Patterns & Traps

The most common reason for HTTP 401/403 errors during Python request replay is a minor canonicalization mismatch:

### Trap 1: JSON Whitespace Formatting
- JavaScript `JSON.stringify({ a: 1, b: 2 })` produces `{"a":1,"b":2}` (no spaces).
- Python default `json.dumps({"a": 1, "b": 2})` produces `{"a": 1, "b": 2}` (with spaces after colons and commas).
- **Fix:** In Python, always specify `json.dumps(payload, separators=(',', ':'))`.

### Trap 2: Parameter Key Sorting
Many backends require query parameters to be sorted lexicographically:
```python
def canonicalize_query(params: dict) -> str:
    sorted_pairs = sorted(params.items(), key=lambda x: x[0])
    return "&".join(f"{k}={v}" for k, v in sorted_pairs)
```

### Trap 3: Clock Skew / Timestamp Drift
If your local computer time differs by more than 30–60 seconds from the server's time, signatures will fail with `Timestamp expired`.
- **Fix:** Fetch the `Date` response header from a pre-flight request to compute server offset:
  ```python
  import email.utils
  server_time = email.utils.parsedate_to_datetime(resp.headers["Date"]).timestamp()
  local_offset = server_time - time.time()
  ```

## 4. Production Python Signature Replay Template

```python
import hashlib
import hmac
import json
import time
import uuid
import requests

API_ENDPOINT = "https://api.target.com/api/v2/search"
SECRET_KEY = "k3y_s3cr3t_pr0duct10n"

def build_signature(path: str, params: dict, body: dict, timestamp: int, nonce: str) -> str:
    # 1. Sort Query Params
    sorted_query = "&".join(f"{k}={params[k]}" for k in sorted(params.keys())) if params else ""
    
    # 2. Compact JSON Body
    body_str = json.dumps(body, separators=(',', ':')) if body else ""
    
    # 3. Form Canonical String
    canonical = f"{path}|{sorted_query}|{body_str}|{timestamp}|{nonce}"
    
    # 4. Compute HMAC-SHA256
    sign = hmac.new(SECRET_KEY.encode('utf-8'), canonical.encode('utf-8'), hashlib.sha256).hexdigest()
    return sign

def search_products(query: str):
    timestamp = int(time.time())
    nonce = str(uuid.uuid4())
    path = "/api/v2/search"
    params = {"q": query, "page": "1"}
    
    sign = build_signature(path, params, None, timestamp, nonce)
    
    headers = {
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/133.0.0.0 Safari/537.36",
        "Accept": "application/json",
        "X-App-Id": "web_v2",
        "X-Timestamp": str(timestamp),
        "X-Nonce": nonce,
        "X-Sign": sign,
    }
    
    response = requests.get(API_ENDPOINT, params=params, headers=headers)
    return response.json()
```

## 6. Response Payload Decryption & Runtime Crypto Sniffing

Many protected APIs return encrypted response bodies (e.g. base64-encoded AES-CBC or AES-GCM ciphertexts) that are decrypted by the frontend client immediately prior to rendering.

### Decryption Triage Workflow:
1. **Verify Client-Side Decryption:** If DevTools Network tab shows raw ciphertext in response bodies (e.g. `{"payload": "u7G3...=="}`), decryption happens client-side in JavaScript or WASM.
2. **Inject Crypto Interceptor:**
   Generate the crypto sniffer via `scripts/devtools_hook_generator.py`:
   ```bash
   python skills/web-reverse/scripts/devtools_hook_generator.py --type snippet --mode crypto
   ```
3. **Capture Plaintext & Keys:**
   Paste the snippet into DevTools Console before triggering the request. The hook intercepts:
   * `CryptoJS.AES.decrypt(ciphertext, key, {iv, mode})` — logs the plaintext JSON, key, and IV.
   * `window.crypto.subtle.decrypt(algorithm, key, data)` — logs the unencrypted ArrayBuffer and key object.
4. **Offline Decryption in Python:**
   Once the key, IV, and mode are extracted, decrypt responses directly in your automated scraper using `pycryptodome` or `cryptography`.
